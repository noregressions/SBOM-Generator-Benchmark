How to read the scores

Content accuracy asks whether the document names what actually ships, at the right version, without passing off test, dev or build tooling as shipped, and with correct hashes. It is measured against each test case's ground truth. Baseline conformance asks whether the document carries the fields the published baselines want. The two disagree, and the disagreement is the point.

Every test case is scanned at up to three stages: source (the checkout, without build outputs or caches), artefact (the built jar, WAR, package or environment) and image (the container). The hidden mechanisms show up as differences between stages, which is why one scan is never enough.
